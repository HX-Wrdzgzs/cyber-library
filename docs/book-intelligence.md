# Book Intelligence

A model can sound certain with very little evidence. Cyber Library therefore stores analysis separately and records the evidence level used.

## L0 — Metadata only

No interpretation. Display verified catalog fields.

## L1 — Catalog analysis

Inputs may include title, author, publisher, subjects, description and publication metadata.

Safe outputs include broad topic, tentative tags and a short explanation. It must not invent chapters, passages, plot events or detailed arguments.

## L2 — Source-backed analysis

Uses legitimate structured or secondary sources such as a table of contents, publisher synopsis, public preview, author notes or openly licensed material. Output is limited to what those sources support.

## L3 — Full-text analysis

Requires legitimate access to the complete text used for analysis. It may support detailed chapter summaries, argument maps, character/concept graphs and structural analysis.

## Required analysis metadata

Every generated analysis should expose level, model/version, generation time, confidence, sources and warnings. Sections without enough evidence are omitted instead of hallucinated.
