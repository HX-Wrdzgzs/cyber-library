# Licensing

Cyber Library's original code in this repository is released under the MIT License.

`phiresky/isbn-visualization` is not vendored here. Its repository contains an AGPLv3 license file. If upstream source is later incorporated, the resulting obligations must be evaluated at that boundary.

Data rights are separate from code licensing. Bibliographic metadata, descriptions, cover images, excerpts and full book text may have different rights and terms. A production catalog should record provenance and rights metadata rather than assuming one software license covers all content.
