# Licensing and rights boundaries

## Cyber Library source code

Original Cyber Library code in this repository is MIT licensed.

## isbn-visualization

`phiresky/isbn-visualization` is a separate project and its repository contains an
AGPLv3 license.

Cyber Library does not include or vendor that project's source code. The ISBN
Universe in this repository is an independent Hilbert-coordinate implementation.

If upstream code is ever imported, the licensing boundary must be reviewed again.

## Open Library data

Open Library publishes separate information about catalog data licensing and notes
that rights questions can vary by contribution/jurisdiction. Always follow the
current Open Library terms and licensing pages rather than treating every external
asset as interchangeable.

## Covers

Cover images are separate copyright objects from catalog metadata.

## Book text

A book being listed in a catalog does not mean its full text is free to republish.

Cyber Library's full-text analysis pipeline therefore requires a caller-provided
rights basis:

- public-domain
- open-license
- licensed
- user-provided

The default implementation stores generated analysis and hashes, not raw full text.

This document is engineering guidance, not legal advice.
