## Open Library

Cyber Library contains an adapter for low-volume, user-triggered Open Library API lookups and scaffolding for Open Library bulk data dumps. It does not redistribute an Open Library dump in this repository.

Software licensing, bibliographic metadata rights, cover-image rights and book-text copyright are separate concerns.
