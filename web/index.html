            这个项目在做什么

            Cyber Library 把 Work（作品）、Edition（版本）、ISBN 与知识分类分开建模。ISBN 空间只表示出版标识符，不拿 ISBN 前缀冒充内容分类。

            公开目录层可以来自 Open Library 月度 dump；实时 API 仅用于低频的人触发查询。全文层只分析公版、开放许可、已授权或用户主动提供的内容。

            ISBN 宇宙使用 Cyber Library 独立实现的 Hilbert 坐标系统，不包含 phiresky/isbn-visualization 源码。
