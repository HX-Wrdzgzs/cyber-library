            GitHub-only 架构

            Cyber Library 的默认公开形态由 GitHub repository、GitHub Actions 和 GitHub Pages 构成，不要求单独服务器。静态目录来自 data/catalog/，Actions 构建 site-data/catalog.json。

            Work、Edition、ISBN 与知识分类分开建模；ISBN 空间只表示出版标识符。来源、许可和分析证据保持独立字段。

            更大的 Open Library 月度 dump 不直接提交进 Git 仓库。仓库保存导入器、引用和可重建规则；公开 Pages 只发布适合 GitHub 静态托管的数据分片。

            完整来源清单、官方文档与 prior art 见仓库 docs/references.md 与 references/。
